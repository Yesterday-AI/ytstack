## Q4. gstack: gbrain, `gbrain:`/`context_queries`, `GSTACK_PLAN_MODE`, runtime requirements, license, telemetry

### Takeaway
gbrain is Garry Tan's separate persistent-knowledge-base project; the `gbrain:` frontmatter is a declarative list of context queries that `bin/gstack-brain-context-load.ts` (bun) runs at skill start and renders `(unavailable)` when gbrain is absent, so it is optional. `GSTACK_PLAN_MODE` is a STATUS line (`active`/`inactive`) printed by `gstack-skill-start` from `CLAUDE_PLAN_FILE`, introduced 2026-05-26 for `/spec`; it does not appear in the three wrapped SKILL.md texts. Runtime: Bun >= 1.4.2 (engines), Node.js only on Windows, `./setup` builds a bundled Chromium browser unless `--no-browser`, Aside browser recommended on macOS; `gstack-setup` as a binary does not exist (it is `./setup`). License MIT unchanged byte-for-byte; telemetry opt-in (default off) but an update check hits GitHub on every interactive skill start by default, and "outside reviews" to Codex are on by default.
