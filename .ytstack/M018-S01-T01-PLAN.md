## What this does

```
yt_pref <yt_dir> <key> [default]
  -> first `key: value` line in <yt_dir>/PREFERENCES.md (frontmatter or body; `key=value` also accepted for legacy ~/.ytstack/config style),
     surrounding quotes stripped, trailing comment after ` #` dropped, whitespace trimmed; prints default when file/key absent
yt_prefs <yt_dir>
  -> YT_PREF_GRANULARITY (task|slice|milestone; default task; invalid -> task + YT_PREF_WARNINGS line)
     YT_PREF_AUTONOMY (step|loop; default loop)
     YT_PREF_QUICK_LANE (on|off; default on)
     YT_PREF_MINIMAL_CODE (on|off; default on)
     YT_PREF_COMMIT_REF_PATTERN (passthrough of commit_ref_pattern, empty when unset)
```

PREFERENCES.md template (init-project) gains:

```markdown
## Ceremony

granularity: task        # task | slice | milestone -- smallest unit that gets a PLAN/SUMMARY pair
autonomy: loop           # loop = chain plan-task -> TDD -> verify -> summarize inside a slice without asking; step = ask before each step
quick_lane: on           # one-sentence changes go through ytstack:quick-task (Q### artifacts), no pitch, no review
minimal_code: on         # inject the minimal-code guard (YAGNI ladder, never-cut list) at session start
```

Tests: defaults when the file is absent; values read from body and from frontmatter; quotes and trailing comments stripped; invalid granularity -> default + warning; `commit_ref_pattern` passthrough; `yt_pref` with explicit default.
