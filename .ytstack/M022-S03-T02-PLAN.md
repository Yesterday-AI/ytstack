## What this does

When the injection is above the guard of 9,500 characters, `hooks/session-start` works out how much of the "Next action" excerpt still fits, keeps that much and ends it with `... (cut: rest in STATE.md)`. When fewer than 200 characters would remain, it prints the one-line note as before. The sentence under the lint block says that a malformed pointer stops `plan-task` and `summarize-task`, and that size and history findings do not block.

The `reconcile` preamble prints `STATE_HISTORY: yes|no` with the number of earlier status paragraphs, the size and the bound, and `CLOSED_MILESTONES` with one line per milestone whose roadmap is `done` and whose slice and task files still lie in `.ytstack/`. The second list is built only when the project has `spec/SPEC.md`.

Step 3 has two more classes, each with its own question. The history class moves earlier status paragraphs verbatim to `.ytstack/archive/<date>/STATE-history.md`; the frontmatter, the current status, "Next action" and "Open decisions" stay. The closed-milestones class moves a milestone's `M###-S##-*.md` files to the archive and leaves its `CONTEXT` and `ROADMAP` in place. Nothing moves without the answer A. The closed-milestones class is the one T03 names; it is in this task because `skills/reconcile/SKILL.md` is one file.
