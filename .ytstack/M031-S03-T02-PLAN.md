# M031-S03-T02 -- Task Plan

**Summary:** A UserPromptSubmit hook tells a session once when the installed plugin is newer than the one it loaded, with the CHANGELOG entry titles in between.

## Files

- Create: `hooks/version-notice`
- Modify: `hooks/hooks.json` (first UserPromptSubmit entry, 5 s)
- Modify: `tests/session-notices.test.sh`, `tests/hooks-json.test.sh`

## What this does

The first prompt of a session records the version of the plugin root the hook runs from in `<state base>/sessions/<session id>/plugin-version`, keyed by the session only. Each prompt compares it with the installed version: the `installPath` of the ytstack entries in `installed_plugins.json` (`${CLAUDE_CONFIG_DIR:-~/.claude}/plugins`), else the newest sibling of the plugin root in the cache without `.orphaned_at`, else the root itself. When the installed one is newer, the hook prints "ytstack X installed, this session loaded A: reload the skills you use" and one line with the entry titles (`- **title**`) of the installed `CHANGELOG.md` between the two versions, cut at 600 characters, and writes `notified-<X>` so each installed version is said once. SessionStart stays read-only. Local files only; any problem ends silent with exit 0.
