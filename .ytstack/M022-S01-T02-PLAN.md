## What this does

`bin/ytstack-spec` is one bash script on git and awk. It sources `hooks/lib/git-ctx.sh` to find the checkout and its `.ytstack` directory and takes `-C DIR` before the mode.

- `lint` checks `SPEC.md` and every area file against `docs/ux/spec-format.md`. Exit 0 clean, 2 warnings only, 1 failures or no spec.
- `drift` lists each area that is not `planned` and whose `paths` have commits after the last commit that touched the area file or one of its `sources`. It skips an area file that is new or edited in the working tree. Exit 0; with `--exit-code` it exits 2 when an area is listed.
- `impact --plan FILE [--grep ERE] [--base SHA]` reads the plan's `## Spec impact`. `none` exits 0. A named area is satisfied when its area file or one of its `sources` changed, committed or not; otherwise exit 1. A plan without the section exits 3.
- `areas [--names] PATH...` names the area whose `paths` cover a path. Exit 1 when a path has no area.

The suite builds fixture repositories under `mktemp` and has one case per rule of the four modes.
