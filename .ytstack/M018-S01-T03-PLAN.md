## What this does

- Enum documented once in `docs/ux/skill-structure.md` under a new "Artifact states" heading; the global `ROADMAP.md` row's Status column mirrors the frontmatter.
- `reassess-roadmap`: preamble lists `M###-ROADMAP.md` files with `status: planned|in-progress` and zero `*-SUMMARY.md` whose newest file is older than 14 days (`find -mtime`), echoes `STALE_MILESTONES`; new step after the deviation review: AskUserQuestion per stale milestone with options `dropped` (plans stay on disk, status written, row updated), `shipped-informally` (work happened outside ytstack: status written + one-line note in `M###-CONTEXT.md`), `keep`; writes the frontmatter (Edit) and the global row.
- `plan-task`: when `M###-ROADMAP.md` says `status: planned`, flip to `in-progress` while writing the first task plan.
- `summarize-task`: when the slice closes and no other slice is open, flip the milestone to `done` and tell the user to update the global row (or do it when the row exists).
- `session-start`: `Milestones in progress: M017, M018` line when >1 (pointer drift smell), computed with `grep -l '^status: in-progress' "$YT_DIR"/M*-ROADMAP.md`.
