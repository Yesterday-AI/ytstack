# M016-S01-T01 -- Task Plan

**Summary:** Create `hooks/lib/git-ctx.sh`, the shared bash-3.2 library every hook and skill preamble sources to read the hook payload, resolve the Git context of the directory the agent actually works in, derive stable repo/worktree keys, and locate the out-of-tree state dir and the `.ytstack` dir. Plus its unit test.

## Files

- Create: `hooks/lib/git-ctx.sh`
- Create: `tests/git-ctx.test.sh`

## What this does

Sourced, never executed (`. "${CLAUDE_PLUGIN_ROOT}/hooks/lib/git-ctx.sh"`). No arrays, no `local -n`, no `flock`, no `readlink -f` (macOS). Every function sets globals prefixed `YT_` and returns 0; callers never need `set -e`.

```bash
yt_sha16 <string>        # printf %s | shasum -a 256 (fallback sha256sum) | first 16 hex chars

yt_read_stdin            # idempotent: if YT_STDIN unset and stdin is not a tty, YT_STDIN=$(cat)
                         # sets YT_CWD, YT_SESSION_ID, YT_HOOK_EVENT, YT_TOOL_CMD, YT_TOOL_EXIT
                         # parser: jq -r '.cwd // empty' ... ; if no jq (or YT_FORCE_NO_JQ=1): python3 -I -c json
                         # YT_CWD is kept only if it is an existing directory; else empty

yt_git_ctx <dir>         # dir defaults to ${YT_CWD:-$PWD}; cd into it in a subshell for every git call
                         # YT_IS_GIT=yes|no   via: [ "$(git rev-parse --is-inside-work-tree 2>/dev/null)" = true ]
                         # YT_TOPLEVEL        canonical (cd && pwd -P) of `git rev-parse --show-toplevel`, or of <dir> when not git
                         # YT_GIT_DIR         `git rev-parse --path-format=absolute --git-dir`  || `--absolute-git-dir`
                         # YT_COMMON_DIR      `git rev-parse --path-format=absolute --git-common-dir` || (cd "$(git rev-parse --git-common-dir)" && pwd -P)
                         # YT_IS_LINKED=yes   iff YT_GIT_DIR != YT_COMMON_DIR   (submodules: both equal -> no)
                         # YT_MAIN_TOPLEVEL   dirname of YT_COMMON_DIR when it ends in /.git, else "" (bare)
                         # YT_REPO_KEY        yt_sha16 "$YT_COMMON_DIR"   (same for every worktree of a repo); non-git: yt_sha16 "$YT_TOPLEVEL"
                         # YT_WT_KEY          yt_sha16 "$YT_TOPLEVEL"

yt_state_base            # echo "${CLAUDE_PLUGIN_DATA:-${PLUGIN_DATA:-${XDG_STATE_HOME:-$HOME/.local/state}/ytstack}}"
yt_state_wt_dir          # echo "$(yt_state_base)/repos/$YT_REPO_KEY/worktrees/$YT_WT_KEY"; mkdir -p;
                         # if mkdir fails: echo "$YT_TOPLEVEL/.ytstack/.local" and mkdir -p that (fallback), YT_STATE_FALLBACK=yes
yt_state_dir             # echo "$(yt_state_wt_dir)/sessions/${YT_SESSION_ID:-nosession}"; mkdir -p

yt_resolve_yt_dir        # echo "$YT_TOPLEVEL/.ytstack" if dir; elif "$HOME/.ytstack/projects/$YT_REPO_KEY" if dir; else ""
                         # sets YT_SCOPE=project|user|none. No basename anywhere.
```

Header comment documents the contract: "`CLAUDE_PROJECT_DIR` is pinned to the session-start dir and does not follow worktrees; hooks must resolve from stdin `cwd` (DECISIONS 2026-11-07)". Keys are 16 hex chars of sha256 for readable paths; the full digest is not needed at this scale.

Test (`tests/git-ctx.test.sh`, same `ok`/`bad`/`new_repo` style as `tests/post-tool-use-bash.test.sh`, fixtures under `mktemp -d` canonicalised with `pwd -P`):
1. main checkout: `YT_IS_GIT=yes`, `YT_IS_LINKED=no`, `YT_TOPLEVEL` == fixture, `YT_MAIN_TOPLEVEL` == fixture.
2. linked worktree (`git worktree add`): `.git` is a file, `YT_IS_LINKED=yes`, `YT_REPO_KEY` equals main's, `YT_WT_KEY` differs, `YT_MAIN_TOPLEVEL` == main fixture.
3. non-git dir: `YT_IS_GIT=no`, keys non-empty, `yt_resolve_yt_dir` empty.
4. submodule checkout: `.git` is a file but `YT_IS_LINKED=no`, `YT_REPO_KEY` != parent's.
5. macOS path spelling: `yt_git_ctx /tmp/...` and `/private/tmp/...` give identical keys (skip on Linux when `/private` is absent).
6. `yt_read_stdin` with jq and with `YT_FORCE_NO_JQ=1`: both yield the same `YT_CWD`/`YT_SESSION_ID`/`YT_TOOL_CMD`; a non-existent `cwd` yields empty `YT_CWD`; no stdin (`</dev/null`) leaves all empty without hanging.
7. `yt_state_dir` honours `CLAUDE_PLUGIN_DATA`, then `PLUGIN_DATA`, then `XDG_STATE_HOME`; with an unwritable base (`/dev/null/x`) it falls back to `<toplevel>/.ytstack/.local/...` and sets `YT_STATE_FALLBACK=yes`.
8. `bash -n` parse check and a `bash --posix`-free run under `bash 3.2` (the macOS `/bin/bash`).
