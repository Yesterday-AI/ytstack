## What this does

New section `# ---------- check: banned patterns (M016 resolver contract) ----------`:
- Files: `skills/*/SKILL.md`, `hooks/*` regular files except `hooks/lib/*` and `hooks/hooks.json`.
- Patterns (grep -n, code lines only = lines not starting with optional whitespace + `#`):
  1. `\[ -d \.git \]`                               -> "use git rev-parse --is-inside-work-tree (git-ctx.sh)"
  2. `basename "\$\(git rev-parse --show-toplevel`   -> "basename slugs collide; use YT_REPO_KEY"
  3. `CLAUDE_PROJECT_DIR` (hooks only)                -> "pinned to session start, does not follow worktrees; use payload cwd via git-ctx.sh"
  4. `~/\.ytstack/\.`                                 -> "sentinel files retired; record state in PROJECT.md frontmatter"
  Each hit = `fail` with file:line.
- Skill preambles that run a shell (```bash / ```!) must source `hooks/lib/git-ctx.sh` -> otherwise `fail` "preamble does not use the shared resolver". Skills without a shell preamble (kind: reference) are exempt.
- Version agreement: `.claude-plugin/plugin.json` `.version` vs `.claude-plugin/marketplace.json` `.plugins[0].version` -> `warn` when different (becomes fail once S03-T03 aligns them; stays warn here so the current tree passes).
