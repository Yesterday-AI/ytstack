# M016-S03-T01 -- Task Plan

**Summary:** Turn the #26 acceptance criteria into one end-to-end suite that snapshots a main checkout byte-for-byte, fires every writing hook with realistic payloads from (a) a session in main, (b) a session in a linked worktree, (c) `CLAUDE_PROJECT_DIR`=main while `cwd`=worktree, and asserts main is unchanged and output is confined to the state dir (or the committing worktree for the stub). Also runs the whole suite under a Linux bash via Docker when available.

## Files

- Create: `tests/hooks-worktree.test.sh`
- Create: `tests/run-all.sh` (runs every `tests/*.test.sh` from a neutral cwd, stops on first failure, `--linux` runs them inside `docker run bash:5` + git when Docker is present)

## What this does

`tests/hooks-worktree.test.sh`:
1. Fixture: repo with `.ytstack/` (STATE pointing at `M042/S03/T07`, committed hand-written `HANDOFF.md`, `PREFERENCES.md`), a linked worktree, `CLAUDE_PLUGIN_DATA` inside the fixture, `ELSEWHERE` as bogus `CLAUDE_PROJECT_DIR`.
2. `snapshot <dir>` = `git status --porcelain` + `find .ytstack -type f | sort | xargs shasum -a 256` of that checkout.
3. For each scenario (a)/(b)/(c) fire in order: `session-start`, `pre-tool-use-edit`, `post-tool-use-bash` (after a `M042-S03-T07:` commit in the scenario's checkout), `pre-compact`, `session-end`, `task-created`, `teammate-idle`, `task-completed` (subject `M042-S03-T08 -- x`). After each hook: main snapshot byte-identical (except in (a) where the stub and the T08 summary legitimately land in main's `.ytstack` -- assert exactly those two files and nothing else), worktree snapshot per scenario (b)/(c): only the stub + summary added in the worktree; everything else (handoff, journal) under `CLAUDE_PLUGIN_DATA`.
4. Idempotency: firing the whole sequence twice adds no new files in any checkout (state dir may grow).
5. Hand-written `HANDOFF.md` sha identical at the end in both checkouts.

`tests/run-all.sh`: `cd "$(mktemp -d)"`, loop over `"$ROOT"/tests/*.test.sh` with `/bin/bash`, print one line per suite, exit 1 on first failure; `--linux`: `docker run --rm -v "$ROOT":/w:ro -w /w alpine/git:latest sh -c 'apk add --no-cache bash jq python3 >/dev/null && bash tests/run-all.sh'` (image has git; falls back to skipping with a clear note when `docker` is absent or the daemon is down). Record the Linux result in the T01 summary.
