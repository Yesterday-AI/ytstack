# M020-S02-T03 -- Task Plan

**Summary:** Exercise native Kimi startup, resume, compaction, real close, pending-context injection and gstack path selection on the installed and current stable CLIs without credentials or external model calls.

## Files

- Modify: `tests/kimi_live_test.py`

## What this does

Extend the existing real Kimi REST fixture to include `bin/`, a target `.ytstack/STATE.md` and captured local-model request bodies. Allow an explicit `KIMI_BIN` so the same suite can run against another isolated CLI binary. Keep temporary HOME/KIMI_CODE_HOME, secret scrubbing and full process cleanup.

Add a native lifecycle test that:

1. Installs the package and verifies all five hooks are present without errors.
2. Waits for SessionStart to prepare pending context, then submits a real prompt through `/prompts` and proves the local model receives the unique project state marker. A second prompt must not repeat it.
3. Triggers `POST /sessions/<id>:compact`; verifies PreCompact's out-of-tree handoff, PostCompact's pending rearm and renewed context on the next prompt. Use enough history for compaction and wait for observable completion.
4. Resumes the persisted session with `kimi --session <id> -p ...` against the local model and proves resume/rearment, without a web idle-unload being mislabeled as SessionStart.
5. Resumes the persisted session in an automated pseudo-terminal, accepts the temporary folder's trust dialog and exits with the implemented Ctrl+C-twice shortcut; verify SessionEnd with reason `exit`. Headless `kimi -p` exit and web shutdown/archive probes did not invoke the handler on 2.5.3, matching upstream #4380's headless gap. Process termination is not the close substitute.

Make the existing override test version-tolerant: Kimi 2.5.3 may return only the winner, while newer catalogs can retain variants. When the server's activation schema accepts `path` and the original is an active variant, activate bare `ship` with the independent gstack `SKILL.md` path and prove that the original loads. If the override hides the original, require an explicit not-found rejection instead. The adapter never treats an exact path as a way to bypass catalog visibility.

Run first with the installed `kimi` 2.5.3. For 2.6.2, the local npm binary failed all operational commands with exit 126 and no diagnostics; run the official npm package in a fresh Node 24 Linux container instead. No project dependency, global upgrade, real provider or external model call. Record both platform results. A discovered product defect requires a failing regression and explicit deviation before a fix.
