# M016-S01-T02 -- Task Plan

**Summary:** Rewrite `hooks/pre-compact` on top of `hooks/lib/git-ctx.sh`: resolve from the payload `cwd`, write the automatic handoff out-of-tree with a `latest-handoff` symlink, never touch `.ytstack/HANDOFF.md`, and emit compaction instructions on stdout.

- Modify: `hooks/pre-compact` (full rewrite, ~80 lines)
- Create: `tests/pre-compact.test.sh`

## What this does

```
. "$(dirname "$0")/lib/git-ctx.sh"
yt_read_stdin                      # cwd, session_id, trigger come on stdin (PreCompact payload)
yt_git_ctx "${YT_CWD:-$PWD}"       # never CLAUDE_PROJECT_DIR; $PWD is the hook's own cwd when no payload
YT_DIR=$(yt_resolve_yt_dir) || exit 0 silently when empty (no .ytstack: write nothing, create no dirs, print nothing)
read STATE.md frontmatter (project, current_milestone, active_slice, active_task) + first 5 lines of "## Next action"
WT=$(yt_state_wt_dir); SESS=$(yt_state_dir)
write "$SESS/HANDOFF.auto.md": frontmatter kind: handoff, event: pre-compact, trigger, timestamp,
  session_id, project, current_milestone, active_slice, active_task, worktree: $YT_TOPLEVEL,
  main_toplevel, ytstack_dir; body: where we are, what to read next (STATE / ROADMAP / REVIEW-NOTES /
  latest SUMMARY), note that .ytstack/HANDOFF.md is user-owned and untouched
refresh symlink atomically: ln -sfn "$SESS/HANDOFF.auto.md" "$WT/.latest-handoff.$$" && mv -f "$WT/.latest-handoff.$$" "$WT/latest-handoff"
stdout (exit 0 => compaction instructions, keep under 9,000 chars):
  "Preserve in the compaction summary: project, position M/S/T, the Next action from STATE.md,
   open decisions and pending user questions, paths: $YT_DIR/STATE.md and $SESS/HANDOFF.auto.md,
   the user's standing instructions for this session."
exit 0 always (fail-open); errors to stderr only
```

The hook must never open `$YT_DIR/HANDOFF.md` for writing, must not create it when absent, and must not create state dirs when no `.ytstack` is resolved.

Test (`tests/pre-compact.test.sh`, fixtures via `mktemp -d`, `pwd -P`, `CLAUDE_PLUGIN_DATA` pointed into the fixture, `CLAUDE_PROJECT_DIR` deliberately pointed at a *different* directory to prove it is ignored):
1. Main checkout with a committed `HANDOFF.md` (`event: user-triggered`): after the hook, `HANDOFF.md` byte-identical (sha256), `git status --porcelain` empty, `sessions/s1/HANDOFF.auto.md` exists with `event: pre-compact`, `session_id: s1`, `current_milestone` from STATE; `latest-handoff` resolves to it; stdout non-empty, mentions the milestone and `STATE.md`, under 10,000 chars.
2. Linked worktree: payload `cwd` = worktree, `CLAUDE_PROJECT_DIR` = main: main and worktree `git status` both empty, auto handoff lands under the worktree's key (different dir from case 1), no `HANDOFF.md` created in the worktree's `.ytstack`.
3. Repo without `.ytstack`: exit 0, empty stdout, no files created under `CLAUDE_PLUGIN_DATA`.
4. Two sessions `s1` then `s2`: both `HANDOFF.auto.md` exist, `latest-handoff` resolves to `s2`.
5. No stdin (`</dev/null`) with the hook's cwd = main: still writes out-of-tree (session `nosession`), `HANDOFF.md` untouched.
6. `.ytstack` without `HANDOFF.md`: the hook does not create one.
7. Fallback: `CLAUDE_PLUGIN_DATA=/dev/null/x` -> auto handoff lands in `<toplevel>/.ytstack/.local/...` and that path is reported on stdout; (gitignore of `.local` is T03 of S02, so here only assert the location).
