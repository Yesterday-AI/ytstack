## What this does

Skill body (directive, not user-invocable; `disable-model-invocation: false` so the Skill tool can load it when the agent is about to write code):

```
# Minimal code
Before writing code, climb the ladder and stop at the first rung that holds:
1. Is it needed at all? (nobody asked; a config flag or deletion solves it)
2. Does the codebase already do it? (grep before you write)
3. Does the standard library do it?
4. Does an existing dependency do it?
5. Is it one line?
6. Otherwise: the minimum that makes the failing test pass -- no options, no abstractions for one caller, no "while I'm here".
Never cut: input validation at trust boundaries, auth/permission checks, error handling at I/O boundaries, accessibility of UI you touch, the one small test for non-trivial logic.
Mark deliberate shortcuts in code with `shortcut:` + reason; ytstack's summarize-task lists them under Follow-ups.
Review question for every diff: which rung, and what did you leave out on purpose?
```

Attribution line in NOTICE under a new "Concepts" entry: the ladder structure is adapted from the ponytail project's idea (MIT, DietrichGebert/ponytail); prose is ytstack's.
