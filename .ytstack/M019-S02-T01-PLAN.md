## What this does

Each case is a user-phrased prompt (never naming the skill), a `fixture.sh` that builds the `.ytstack/` state the skill expects (STATE pointer, plans, summaries, git commits), and two free graders: `tool_used: Skill` with `input_match` on the skill name (plugin-fired indicator) and a `file_exists` / `regex { source: file }` check on the artifact the skill must produce. `runs: 1` keeps the suite affordable; `max_turns` 30-40 because the skills run preambles, read plans and write files. `append_system_prompt`: headless, take each RECOMMENDATION, never wait for input. Run: `claude plugin eval . --trust-plugin --scaffold --allow-tools Write Edit Bash --ablation none --no-publish --max-cost-usd 10`.
