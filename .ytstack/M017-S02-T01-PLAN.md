## What this does

```
YT_GSTACK_PIN="1.96.0.0"                 # ytstack's tested gstack release (tag v1.96.0.0, 2026-11-05)
yt_vergte <a> <b>                         # dotted-numeric compare, returns 0 when a >= b (bash 3.2, no arrays)
yt_gstack_ctx
  YT_GSTACK_DIR="${GSTACK_HOME:-$HOME/.claude/skills/gstack}"
  YT_GSTACK_AVAILABLE=yes iff "$YT_GSTACK_DIR/VERSION" is a file AND office-hours/plan-ceo-review/plan-eng-review SKILL.md exist
  YT_GSTACK_VERSION=$(first line of VERSION, trimmed; "" when absent)
  YT_GSTACK_PIN_OK=yes iff yt_vergte "$YT_GSTACK_VERSION" "$YT_GSTACK_PIN"
  YT_BUN=$(command -v bun), YT_BUN_VERSION=$(bun --version), YT_BUN_OK=yes iff >= 1.4.2
  YT_GSTACK_INSTALL_CMD="git clone --branch v$YT_GSTACK_PIN https://github.com/garrytan/gstack \"$YT_GSTACK_DIR\" && (cd \"$YT_GSTACK_DIR\" && ./setup --no-browser)"
yt_gstack_skill_ok <name>                 # echo yes|no for "$YT_GSTACK_DIR/<name>/SKILL.md"
```

Tests: empty HOME -> AVAILABLE no, VERSION "", PIN_OK no, INSTALL_CMD names the pin and dir; fake install (VERSION `1.96.0.0`, three SKILL.md) -> AVAILABLE yes, PIN_OK yes, each `yt_gstack_skill_ok` yes, missing fourth skill no; VERSION `1.95.3.0` -> PIN_OK no; `GSTACK_HOME` override wins over HOME; `yt_vergte` table (1.96.0.0 >= 1.96.0.0, 1.100.0.0 >= 1.96.0.0, 1.9.0.0 < 1.96.0.0, 2.0 >= 1.96.0.0); bun: `YT_BUN_OK` yes on this machine (1.4.4), and with `PATH=/nonexistent` -> no.
