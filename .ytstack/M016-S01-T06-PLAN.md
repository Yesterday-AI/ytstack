## What this does

- `SessionStart.matcher`: `startup|resume|clear|compact|fork` (forked sessions since v2.1.214 otherwise start without the directive).
- Every `type: command` entry gets `"shell": "bash"` (superpowers v7 pattern; makes the interpreter explicit on hosts whose default shell is not bash).
- `SessionEnd.timeout`: 5 -> 2 with the `description` noting the 1.5 s default plugin budget; the hook itself now runs in ~0.3-0.5 s.
- No `onFailure: "block"` anywhere. Deviation from the M016 exit criterion ("`onFailure: block` only on `pre-tool-use-edit`"): that hook is advisory by design (issue #19 made a blocking exit a P0); a crash in an advisory hook must not block edits. Recorded in CONTEXT.
- Keep `async: false` everywhere (`PreCompact` output must be synchronous to serve as compaction instructions).
