## What this does

A recipe of under 90 lines. It says what the run does and what it may leave behind: one question file or one issue, never a product change, never a commit, never a merge.

Then one subsection per variant with the smallest working setup:

- Plain CI, the recommended default: a complete scheduled GitHub Actions workflow that runs the script without a model and opens one issue; a crontab line for one machine.
- Claude Code: a headless run (`claude -p`) from a system scheduler, a cloud scheduled task (`/schedule`) and `/loop`, each with its limit.
- The other host: what `docs/codex.md` supports, and `codex exec` from a system scheduler.

The syntax comes from the current documentation and from the help output of the installed command line tools, not from memory. A closing section says what was verified by running, what was only read, and what is untested.
