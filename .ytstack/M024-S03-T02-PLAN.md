## What this does

`bin/ytstack-questions` keeps the queue of what only the human can decide: one file per question, `.ytstack/questions/Q###-<slug>.md`, in the format of `docs/ux/coordinator-format.md`.

`new --question <text> --decides <who> [--blocks <refs>]` writes the next id after the highest one, a slug from the question, the frontmatter with `state: open` and the four empty sections Context, Options, Recommendation and Answer. `list` prints one tab separated line per file, the open and asked ones by default, one state with `--state`. `next` prints the oldest open question and exits 1 when none is open.

`ask <id>` sets `state: asked` with its time and is refused for a question that is not open: a question is asked once. `answer <id>` sets `state: answered` with its time and is refused without text under `## Answer`. `ask` and `answer` change the frontmatter only; the text of an answer is written by whoever heard it, never by the script. `check` validates the files: ids unique and equal to the file name, a listed state, `asked` and `answered` set exactly when the state says so, text under `## Answer` in an answered file.
