## What this does

Evidence is a check, run on a commit, in an environment. The verifier still makes the independent run: each plan's command, on the head it was given, as often as the plan's `Runs:` line says. It renews a check when the commit changed in files that check covers, the environment differs, the earlier run failed or flaked, or no independent run exists for this commit. When its brief or the summary carries an earlier verifier verdict and the plan's files are unchanged since that commit, it cites the verdict instead of running the command again. Its verdict block names the commit. It adds no passes, scenarios or suites, does not turn a finding the project's policy rates non-blocking into a FAIL, and ends with `Not checked:`.

`verification-before-completion` prints the plan's `Runs:` line and the short HEAD. It runs the command that often, in that environment, and notes the commit with the output. The vendored "run it fresh" now means fresh for the commit being claimed: a result with output for this commit in this environment stands, a result for an older commit does not. A check the project requires for every change stays required.

`summarize-task` writes the Verification line with the result, the short SHA and the environment, followed by `Not checked:`. The line records the run that was already made; closing a task is not a reason to run the check again.
