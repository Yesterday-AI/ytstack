## What this does

`tests/hooks-concurrency.test.sh`:
1. Fixture main checkout with `.ytstack/` + committed `HANDOFF.md`; `CLAUDE_PLUGIN_DATA` in the fixture.
2. Interleave: `pre-compact` s1, `pre-compact` s2, `session-end` s1, `session-end` s2, `pre-compact` s1 (again), `session-end` s2 (again) -- each as a separate process, s1 and s2 alternating; additionally fire 5 `pre-compact` for s1..s5 **in parallel** (`&` + `wait`).
3. Assert: `sessions/s1/HANDOFF.auto.md` and `sessions/s2/HANDOFF.auto.md` both exist with their own `session_id`; `latest-handoff` resolves to the session fired last; `sessions/s1/session.jsonl` has 1 line and `sessions/s2/session.jsonl` has 2; after the parallel burst all five session dirs exist and `latest-handoff` resolves to one of them and is a valid symlink (no dangling `.latest-handoff.<pid>` temp files left); every `session.jsonl` line is valid JSON; `.ytstack/HANDOFF.md` sha unchanged; main `git status` clean.
4. Idempotency on the stub: `post-tool-use-bash` fired three times for the same commit creates exactly one SUMMARY file whose sha does not change.

`bin/ytstack-check --tests`: when the flag is present, after the static checks run `tests/run-all.sh` via `subprocess` and fold its exit code into the result (fails become `[fail] tests: <suite>`).
