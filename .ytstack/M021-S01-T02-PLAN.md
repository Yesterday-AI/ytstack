## What this does

Input: status line JSON on stdin (only `cwd` is used, through `yt_read_stdin`); without usable input the script falls back to `$PWD`. Flag `--no-color`; a non-empty `NO_COLOR` does the same.

Resolution: `yt_git_ctx` + `yt_resolve_yt_dir`. No `.ytstack` or no `STATE.md`: no output, exit 1.

Task pointer: `current_milestone` / `active_slice` / `active_task` from the local `STATE.md`; parts that are `none`, `all` or malformed are left out.

Plan progress: in a project-scope git checkout whose current branch is not the default branch, `STATE.md` is read with `git show` from the newer of `origin/<default>` and the local `<default>`; the default branch comes from `origin/HEAD`, else `main`, else `master`. Otherwise, or when that read yields nothing, the working tree file is used. Local refs only, no network.

- block `bad`, or neither block nor pointer: no output, exit 1
