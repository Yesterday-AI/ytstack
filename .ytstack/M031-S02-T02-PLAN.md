## What this does

`route` takes `--pr N` (a number). With it the first line names the pull request (`lane: <ref>; author: <worker>; plan: <path | none>; pr: #<n>`), `ytstack-risk route` gets `--pr N`, and `--plan` only when the lane has a plan file. A lane without a plan file is then routed from the host's reviews instead of `route: person` with "no plan file". Without `--pr` nothing changes: no host is read. The stand-in `gh` of the suite answers the reviews endpoint from a fixture.
