## What this does

Skill contract: frontmatter (`name: quick-task`, description = trigger-only: "Use for a change you can describe in one sentence (fix, tweak, rename, bump, small refactor) in a project with `.ytstack/` when PREFERENCES `quick_lane` is on; writes Q###-PLAN/SUMMARY under .ytstack/quick/ and requires a verification command. Not for new features or anything touching more than ~3 files -- use plan-task."), `tier: core`, `version: 0.1.0`, `allowed-tools: Bash, Read, Write, Edit, AskUserQuestion`.

Preamble: resolver block; `yt_prefs`; `NEXT_Q` = next free `Q###` under `.ytstack/quick/` (start `Q001`); echoes `HAS_YTSTACK`, `QUICK_LANE`, `NEXT_Q`, `BRANCH`.

Procedure:
1. HARD-GATE: `HAS_YTSTACK=no` -> "run init-project / adopt-brownfield"; `QUICK_LANE=off` -> "quick lane is off in PREFERENCES; use plan-task"; stop.
2. Fit check (no question): the user's sentence names the change; if it mentions a new feature, a migration, more than ~3 files or an unknown root cause, say so and route to `plan-task` / `systematic-debugging`; stop.
3. Write `.ytstack/quick/{NEXT_Q}-PLAN.md` (frontmatter `kind: quick`, `created`, `status: in-progress`; body: the sentence, Files, Verification command). Create `.ytstack/quick/` on first use.
4. Execute via `ytstack:test-driven-development` (RED/GREEN on the verification), then `ytstack:verification-before-completion`; commits carry `{NEXT_Q}:` as subject prefix.
5. Write `{NEXT_Q}-SUMMARY.md` (Outcome, Verification output, Commits via `yt_task_commits "$_PROJECT_DIR" "^{NEXT_Q}:"`), flip PLAN `status: done`. No STATE.md pointer change; `last_updated` bumped only.
6. Report: path + one line; Terminal State: return (no auto-chain -- the quick lane is complete in itself).

`using-ytstack`: in the skills list "Execution discipline" add `quick-task`; in "The rule" add one sentence: one-sentence fix/tweak/rename/bump intents in a `.ytstack` project with `quick_lane: on` route to `quick-task`, not `plan-task`.

Tests: skill-preambles suite -- `quick-task` runs in main + worktree with `HAS_YTSTACK: yes`, echoes `QUICK_LANE: on` (default) and `NEXT_Q: Q001` in a fixture without `.ytstack/quick/`; with `quick/Q001-PLAN.md` present -> `NEXT_Q: Q002`.
