# M016-S02-T02 -- Task Plan

**Summary:** Make commit discovery configurable and worktree-aware: a shared `yt_commit_ref_pattern` / `yt_task_commits` in the library (used by `summarize-task` and `post-tool-use-bash`), `commit_ref_pattern` from `PREFERENCES.md`, and a branch-based fallback (`merge-base..HEAD`) for squash-merge / conventional-commit repos so a summary never claims "shipped uncommitted" when commits exist.

## Files

- Modify: `hooks/lib/git-ctx.sh` (two functions)
- Modify: `skills/summarize-task/SKILL.md` (preamble discovery block + Step 8 `## Commits` wording)

## What this does

```
yt_commit_ref_pattern <yt_dir> <M> <S> <T>
  -> echo the ERE: PREFERENCES.md `commit_ref_pattern:` (quotes stripped, taken literally) or default '^M###-S##-T##:',
     with tokens M### / S## / T## / {task} rendered
yt_task_commits <toplevel> <pattern>
  -> sets YT_COMMITS (lines '- `%h` -- %s'), YT_COMMITS_SOURCE=task-ref|branch|none
     1. git -C <toplevel> log --no-merges -E --grep "<pattern>" ; if non-empty: source=task-ref
     2. else base = merge-base of HEAD with origin/HEAD, else origin/main, else main, else master (first that resolves and differs from HEAD);
        git log --no-merges base..HEAD ; if non-empty: source=branch
     3. else none
```

`summarize-task` preamble: replace the inline `git log --grep "^$_TASK_REF"` with the two calls (lib available) or the same logic inline in the fallback branch; echo `TASK_COMMITS_SOURCE`. Step 8: write `## Commits` with the source label: task-ref -> list; branch -> "No commit carried the task ref `...`; commits on this branch since <base>:" + list; none -> "No commits found for this task (neither by ref `...` nor on the current branch)." Never the old "shipped uncommitted or under a non-conventional message" guess.

`post-tool-use-bash`: `PATTERN=$(yt_commit_ref_pattern "$YT_DIR" "$CURRENT_MILESTONE" "$ACTIVE_SLICE" "$ACTIVE_TASK")`; behaviour unchanged (19 tests stay green).

Tests (append to `tests/git-ctx.test.sh`): default pattern rendering; custom pattern with `{task}`; quotes stripped; task-ref discovery finds 2 of 3 commits; branch fallback on a feature branch with conventional-commit subjects (source=branch, base excluded); none on a fresh branch with no new commits; in a linked worktree discovery runs against the worktree's HEAD.
