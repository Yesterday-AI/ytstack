## What this does

```
yt_state_lint <yt_dir>   # sets YT_STATE_WARNINGS ("" when clean), YT_STATE_WARN_COUNT
  reads STATE.md frontmatter: current_milestone, active_slice, active_task, last_updated
  W1 malformed: current_milestone not M### or none; active_slice not S##|all|none; active_task not T##|all|none; last_updated not ISO-8601 (YYYY-MM-DDTHH:MM:SSZ)
  W2 pointer behind: newest M###-CONTEXT.md (or M###-ROADMAP.md) has a higher number than current_milestone
  W3 closed task still active: active_task != none and <M>-<S>-<T>-SUMMARY.md exists with `closed:` not `draft`
  W4 slice/task set while milestone is none
  W5 stale timestamp: last_updated older than the newest commit touching <yt_dir> (git log -1 --format=%cI -- <yt_dir>), only when git is available
  W6 milestone done but still current: <M>-ROADMAP.md status: done while current_milestone = <M> and active_slice != none
```

Tests (fixtures in a temp repo with `.ytstack/`): clean STATE -> no warnings; each W1..W6 triggered individually -> exactly the expected line (substring match); two at once -> count 2; missing STATE.md -> single "STATE.md missing" line.
